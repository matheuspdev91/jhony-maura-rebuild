# JHONY & MAURA — FOUNDATION RULES

## Authority

The existing Foundation Design System is the project's design system and source of truth.

Use Foundation tokens, utilities, components and layout primitives whenever they already solve a requirement.

Do NOT create a second design system.

Do NOT recreate existing Foundation values for:
- colors
- typography
- spacing
- transitions
- generic layout
- generic buttons
- generic surfaces

Custom CSS is allowed only for presentation or composition that is genuinely specific to the Jhony & Maura landing page.

## Priority

1. Foundation
2. Minimal page-specific CSS
3. Minimal JavaScript for behavior that CSS/native browser behavior cannot handle

Never replace Foundation with a parallel system.
